Mô tả

  • Level không nằm trong file riêng: nó là một chuỗi trong Remote Config, key map_config_<map>_lv_<n> (APK mặc định) hoặc map_config_<map>_lv_all_override_default (server, 100 level một key).
  • Mỗi level là chuỗi customers~grid~queue; mỗi phần có thể bị nén thành z1_ + base64url của raw-deflate. Metadata ngắn đi kèm (weather;difficulty;khách;món;nguyên liệu;tutId) nằm ở lv_metadata.
  • Độ khó có 3 mức: Normal / Hard / SuperHard, thưởng thắng 20 / 60 / 100 gem. Hard và SuperHard rơi theo nhịp cố định (vd burger: Hard ở level 5, 10, 20, 25...; SuperHard ở 15, 30, 40, 50...).
  • Server đang ghi đè 13 map (1.090 level) bằng bản default; bento (APK chỉ 30 level chơi được, server 100), pizza (APK 100, server 30), croissant (Preview) và tacos (chỉ có trong RC) cho thấy server quyết định phát hành level, không cần build mới.

Tóm tắt thiết kế

  • Code Level là dữ liệu Remote Config: mặc định 1.100 level trong APK, server ghi đè cả map bằng một key ..._lv_all_override_default (100 level nối bằng &). Đổi cân bằng không cần build.
  • Code Chuỗi level customers~grid~queue, mỗi phần có thể nén z1_ (raw-deflate + base64url). Level 1 burger chỉ 4 khách, 6 món, 15 nguyên liệu, 3 cột queue.
  • Live 16/11 Server đang chạy 13 map, 1.090 level; 296 level khác APK. bento mở 100 level (APK chỉ 30), pizza giảm còn 30 (APK 100), croissant và tacos mỗi map 30 level chưa chơi được.
  • APK Độ khó chia Normal / Hard / SuperHard, tỉ lệ khoảng 70 / 20 / 10 mỗi map. Burger: Hard ở level 5, 10, 20, 25...; SuperHard ở 15, 30, 40...; các map khác SuperHard mỗi 10 level từ level 10.
  • Playtest Thưởng thắng đi theo độ khó: Normal +20 gem, Super Hard +100 gem (Day 15, nút có quảng cáo thưởng). Màn Hard / Super Hard có nút Day màu tím / đỏ và banner riêng.
  • Code RemoteConfigOverrideAuthorSelector cho phép mỗi người thiết kế (anhpd, daivq, linhnht, tantd) giữ bộ level riêng bên cạnh default để thử, người chơi luôn dùng default. Ngày 16/11 server không chạy thử nghiệm A/B nào.

Luồng người chơi từng bước

  1. Mở level từ nút DayNgười chơi Playtest
    Nút Day hiện màu theo độ khó (đỏ Super Hard, tím Hard).
  2. Lấy chuỗi levelHệ thống Code
    Ưu tiên bộ default của server nếu có, không thì map_config_<map>_lv_<n> trong APK.
  3. Giải nén và tách 3 phầnHệ thống Code
    ProcessLevelDesignData tách theo ~; phần z1_ qua LevelStringCompression.Decode.
  4. Dựng khách, lưới, hàng đợiHệ thống Code
    3 translator parse; lỗi thì quay về chuỗi mặc định.
  5. Thắng: thưởng theo độ khóGiao diện Playtest
    Normal +20 gem; Super Hard +100 gem.
  6. Thua level khóGiao diện Playtest
    Day 20 Hard: "Too Tough!" (Day 15 thua: "Kitchen Chaos!").

  • Đưa toàn bộ level lên Remote Config theo từng map, một key cho cả map: đổi cân bằng, mở bớt hoặc thêm level mà không cần build.
  • Giữ một bộ level mặc định đóng gói làm lưới an toàn: chuỗi server hỏng thì quay về bản gốc thay vì làm hỏng level.
  • Cho mỗi người thiết kế một id tác giả để thử bộ level riêng song song với bản default, người chơi chỉ thấy default.

Bảng tổng hợp mọi tính năng đã làm chi tiết: FoodiePop_ThietKeChiTiet.xlsx.

Mở khóa & điểm vào

Không có điều kiện mở khoá riêng. Level mở theo tiến độ Day / map (xem MapProgression). Level thiết kế hỏng thì LevelPlayLoadAndSetupControl.ProcessLevelDesignData quay về giá trị Remote Config mặc định của level đó.

Điểm vào:

  • Người chơi bấm nút Day trên Home: level được nạp từ chuỗi RC
  • Màn Hard / Super Hard: nút đỏ / tím trên Home và banner "SUPER HARD DAY!"
  • Công cụ QA RemoteConfigOverrideAuthorSelector (OnGUI, trong scene Boot) chọn bộ level của một tác giả

Cách hoạt động

  1. Boot: RemoteConfigDefaultSetterCakeOrder nạp mặc định APK: _mapConfig[] (11 map) với levelDesigns[], lv_metadata, tool, upgrade_building.
  2. Server gửi key override: GetRemoteKeyForAuthorLevelOverride(map, author) = map_config_<map>_lv_all_override_<author>. Giá trị = lv_metadata + & + level 1 + & + level 2...
  3. SelectOverrideAuthor(author) (mặc định default) áp bộ level của tác giả đó lên lv_metadata và từng map_config_<map>_lv_<n>.
  4. Vào level: LevelPlayLoadAndSetupControl.ProcessLevelDesignData(levelDesignStr) tách chuỗi theo ~ thành 3 phần.
  5. CustomerOrderTranslator.Parse, GridLayoutTranslator.Parse, IngredientQueueTranslator.Parse giải mã từng phần; phần bắt đầu bằng z1_ đi qua LevelStringCompression.Decode (tối đa 1 MiB sau giải nén).
  6. MapLevelMetadataConfig.GetLevelConfig(i) trả SingleLevelMetadata (thời tiết, độ khó, tutId).
  7. Nếu dựng lịch khách / hàng đợi lỗi: log "[LevelDesign] Using the default Remote Config value" và thử lại bằng chuỗi mặc định; lỗi nữa thì dừng.
