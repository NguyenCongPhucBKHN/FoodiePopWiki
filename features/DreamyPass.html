Mô tả

  • Battle pass theo tháng: 31 mốc (0-30), mỗi mốc có thưởng Free và thưởng Pass trả phí.
  • Điểm đến từ thắng level: 1 điểm level thường, 3 điểm level khó, 5 điểm level siêu khó.
  • Mua Pass (IAP foodiepass) mở thưởng Pass và +8 tim tối đa trong thời gian pass; điểm vượt mốc cuối đổi thành Bonus Bank (gem).
  • Mặc định mở ở level 35 (RC level_unlock_dreamy_pass); playtest 16/11 (Day 13-20) chưa thấy.

Tóm tắt thiết kế

  • Code Pass theo tháng: endTime = giây cuối tháng khi người chơi bấm Start; mỗi tháng reset điểm, trạng thái mua và thưởng.
  • Code Điểm theo độ khó level: 1 / 3 / 5, nên người chơi gặp level khó được tiến Pass nhanh hơn.
  • APK Thưởng Pass gần gấp đôi Free ở hầu hết mốc (ví dụ mốc 25: 200 gem so với 600 gem); mốc 0 Pass tặng Frame 10 + NameFx 1 (mỹ phẩm hồ sơ).
  • Code Mua Pass cộng +8 tim tối đa và đầy tim ngay (FillHeartsForBonus): lợi ích chơi được, không chỉ thưởng điểm.
  • Code Điểm vượt mốc cuối không bị bỏ phí: KeysPastLastReward đổi thành Bonus Bank (5 mỗi chìa, trần 3000).
  • Live 16/11 Save Day 20: DreamyPassDbModel rỗng (endTime 0, chưa activated); RC live không có level_unlock_dreamy_pass.

Luồng người chơi từng bước

  1. Mở khoá và StartNgười chơi Code
    Qua level 34, popup mở khoá, bấm Start đặt hạn cuối tháng.
  2. Thắng level, cộng điểmNgười chơi Code
    +1 / +3 / +5 điểm theo độ khó, thanh tiến độ chạy.
  3. Nhận thưởng FreeNgười chơi Code
    Mỗi mốc đạt nhận ô Free, không cần mua.
  4. Mua PassNgười chơi Code
    IAP foodiepass: mở ô Pass, tim tối đa +8, đầy tim.
  5. Điểm vượt mốcHệ thống Code
    Điểm trên 977 vào Bonus Bank.
  6. Hết thángHệ thống Code
    Nhắc thưởng chưa nhận, reset mùa mới.

Vận dụng cho game khác

  • Bậc Free + bậc trả phí chung một thanh tiến độ: ai cũng thấy phần thưởng cao hơn mình bỏ lỡ.
  • Lợi ích chơi được (tim tối đa +8) làm động cơ mua mạnh hơn chỉ gem.
  • Điểm theo độ khó khuyến khích người chơi thử level khó thay vì bỏ qua.

Bảng tổng hợp mọi tính năng đã làm chi tiết: FoodiePop_ThietKeChiTiet.xlsx.

Mở khóa & điểm vào

DreamyPassManager.IsUnlocked = SODreamyPassConfig.IsEnabled (RC level_unlock_dreamy_pass > 0) và MainLevelCompleted >= giá trị - 1. Mặc định DefaultLevelUnlock = 35 (Code, APK), khớp bản 1.11. RC live 16/11 không có key. Save Day 20: playTutUnlock = false.

Điểm vào:

  • Icon Pass trên Home (DreamyPassFIconCtrl, chấm thông báo HasUnclaimedReward)
  • Popup mở khoá PopupDreamyPassUnlockCtrl (tự bật 1 lần)
  • Popup bắt đầu mùa PopupDreamyPassStartCtrl
  • Mục Profile (khung / hiệu ứng tên VIP) gọi DreamyPassManager.OpenPass (FrameItemUICtrl, NameFxItemUICtrl)

Cách hoạt động

  1. Đủ level: CheckPlayTutorialUnlock mở PopupDreamyPassUnlockCtrl (playTutUnlock).
  2. Lần đầu mở: CheckShowTutFirstOpen / PopupDreamyPassFirstOpenCtrl giải thích Free và Pass.
  3. Bấm Start mùa: PopupDreamyPassStartCtrl.StartNewSeason đặt endTime = cuối tháng.
  4. Thắng level: LevelPlayController.OnLevelWin gọi DreamyPassManager.ChangePointWinLevel(level) (+1 / +3 / +5), chỉ khi đã mở khoá, đã Start và chưa hết mùa.
  5. Điểm tăng: GetLevelByPoint tính mốc đạt; mỗi mốc mới log foodie_pass_pass.
  6. Nhận: ClaimFreeReward(level) hoặc ClaimPassReward(level) (cần activated), hoặc ClaimAllReward.
  7. Mua Pass: PopupDreamyPassActivateCtrl.PurchaseActivatePass -> OnIapPurchased -> ActivatePass (activated = true, +8 tim tối đa, đầy tim).
  8. Điểm vượt mốc cuối cộng vào extraPoint (Bonus Bank), mở bằng PopupDreamyPassBonusBankCtrl.
  9. Hết tháng: PopupDreamyPassFinish / PopupDreamyPassUnclaimedRewardCtrl, rồi ResetDataNewSeason.
