Mô tả

  • Sự kiện leo tháp 66 tầng bằng chuỗi thắng level chính: thắng +1 tầng, thua rơi về mốc an toàn gần nhất.
  • Có 8 mốc an toàn (tầng 0, 5, 11, 17, 22, 33, 42, 65) và 10 tầng có thưởng; tầng 65 là thưởng lớn (1000 gem + tim vô hạn 30 phút + 4 booster (Magnet, Swap, Bell, Stack Box)).
  • Mỗi vòng kéo dài 3,5 ngày (Thứ Hai 00:00 và Thứ Năm 12:00 UTC), hết vòng thì reset về tầng 0.
  • Mặc định mở ở level 61 (đọc từ RC level_unlock_dreamy_tower); khác bản 1.11 ghi level 31.

Thiết kế chi tiết

Cập nhật 16/11/2026 · đọc lại code 1.15 + asset SODreamyTowerConfig + save 16/11

Tóm tắt thiết kế

  • Code Thắng +1 tầng, thua rơi về mốc an toàn: GetLevelChecked trả mốc cao nhất không vượt tầng hiện tại, nên mốc rải dày ở đầu (5, 11, 17, 22) rồi thưa dần (33, 42, 65).
  • Code Thoát app giữa level bị tính là thua (onPlayingLevel), chặn việc thoát để giữ chuỗi.
  • APK Đỉnh tháp (tầng 65) trả 1000 gem + tim vô hạn 30 phút + 4 booster, rất xa so với các tầng giữa; tổng gem cả tháp 1850.
  • Code Mốc mở khoá đọc từ RC level_unlock_dreamy_tower, mặc định 61 (1.11 ghi 31): sự kiện dời xa hơn trong hành trình người chơi.
  • Live 16/11 Save Day 20 đã có DreamyTowerDbModel với endTime 19/11 12:00 UTC dù chưa mở khoá: model được tạo sẵn khi khởi động.

Luồng người chơi từng bước

  1. Qua level mở khoáHệ thống Code
    Bật popup mở khoá 1 lần, icon Tháp hiện trên Home.
  2. Thắng liên tiếpNgười chơi Code
    Mỗi level thắng lên 1 tầng; qua tầng thưởng hiện popup nhận.
  3. Thua một levelNgười chơi Code
    Rơi về mốc an toàn gần nhất (ví dụ tầng 20 về tầng 17).
  4. Hết vòngHệ thống Code
    Thứ Hai 00:00 hoặc Thứ Năm 12:00 UTC reset về tầng 0, thưởng nhận lại được.

  • Chuỗi thắng không phạt hoàn toàn: rơi về mốc chứ không về 0 giữ động lực chơi tiếp sau thua.

Mở khóa & điểm vào

DreamyTowerManager.IsUnlocked = SODreamyTowerConfig.IsEnabled (RC level_unlock_dreamy_tower > 0) và MainLevelCompleted >= giá trị đó - 1. Mặc định DefaultLevelUnlock = 61 (Code, APK). RC live 16/11 không có key nên vẫn là 61. Playtest Day 20 (đã xong 19 level): chưa mở.

Điểm vào:

  • Icon Tháp trên Home (DreamyTowerFIconCtrl)
  • Popup mở khoá PopupDreamyTowerUnlockCtrl
  • Popup nhận thưởng tự bật ở Home (CheckShowPopupClaimReward trong R1HomeFlow)
  • Thanh tầng trong level (DreamyTowerLevelUICtrl) và DreamyTowerLosePanel khi thua

Cách hoạt động

  1. Đủ điều kiện mở khoá: CheckPlayTutorialUnlock bật PopupDreamyTowerUnlockCtrl 1 lần.
  2. Mở tháp lần đầu: CheckFirstOpenPopup hiện PopupDreamyTowerInfoCtrl.
  3. Vào level chính: SetOnPlayingLevel đặt onPlayingLevel = true.
  4. Thắng: HandleWinStreak tăng level +1, cập nhật ProfileManager.ChangeDreamyTowerMax, QuestsManager.SetQuestCounter(ReachDreamyTower), log dreamy_tower_win_streak.
  5. Thua hoặc thoát giữa chừng: HandleLoseStreak đưa level về GetLevelChecked (mốc an toàn gần nhất), log dreamy_tower_lose_streak.
  6. Về Home: CheckShowPopupClaimReward mở popup khi vừa qua tầng có thưởng; ClaimRewardCheckPoint đánh dấu đã nhận.
  7. Hết vòng (endTime): ResetData về tầng 0, xoá trạng thái nhận.

Còn thiếu / chưa xác minh

  • Mảng R1Features.ReleasedEvents (6 trong 7 giá trị R1Event) nạp từ dữ liệu tĩnh trong .cctor nên chưa đọc được event nào bị tắt; R1Features.IsEventEnabled quyết định R1HomeFlow có chạy bước kiểm tra của event hay không.
  • Chưa thấy icon / popup khi chơi: Day 20 chưa tới level 61.
  • Giá trị SODreamyTowerConfig.MaxLevel (suy luận = 65) chưa đọc trực tiếp.
  • Có dùng quảng cáo / hồi sinh để tránh rơi tầng hay không: chưa thấy trong DreamyTowerLosePanel.
