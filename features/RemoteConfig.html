Mô tả

  • Foodie Pop dùng Firebase Remote Config làm bảng điều khiển live: 1 174 key mặc định đóng trong APK, server live 16/11 chỉ ghi đè 17 key (template 290).
  • Gần như mọi con số cân bằng (tim, booster, quảng cáo, IAP, đánh giá game, cập nhật) đọc từ key JSON hoặc chuỗi a;b;c|..., nên đổi được không cần build mới.
  • Phần lớn dung lượng là dữ liệu level: 11 map × 103 key (map_config_<map>_lv_N, lv_metadata, tool, upgrade_building) và key ghi đè cả map map_config_<map>_lv_all_override_<author>.
  • Boot luôn chọn author default, nên 13 key ..._lv_all_override_default trên server thay dữ liệu level của client (kể cả 2 map chưa có trong APK).
  • Không có thử nghiệm A/B Firebase (abt_experiments_key rỗng) và không có rollout; "A/B" ở đây là chọn bộ level theo author cho QA.

Thiết kế chi tiết

Cập nhật 16/11/2026 · đọc lại code 1.15 + đối chiếu 2 file RC (APK và live 16/11)

Tóm tắt thiết kế

  • APK 1 174 key mặc định (1.11: 863): 11 map × 103 key dữ liệu level + 41 key cấu hình chung. Con số tăng vì thêm 3 map (+ key chung).
  • Live 16/11 Server chỉ ghi đè 17 key (template 290): 13 override level, league_config, ads_network_config, new_version_popup, popup_blur_opengl_mode. Không có thử nghiệm A/B hay rollout.
  • Code Fetch theo chuỗi SetDefaultsAsync → FetchAsync → ActivateAsync, chờ tối đa 4 giây rồi vẫn vào game bằng mặc định (RemoteConfigManager.StartTimeout).
  • Code Boot release luôn chọn author default nên key lv_all_override_default của server là bộ level người chơi thật nhận; designer có thể đổi level mà không build lại.
  • Nhận định Mô hình "mặc định trong APK + ghi đè bằng key server" cho phép ship map mới (tacos, croissant) bằng dữ liệu trước khi có code hiển thị.

Luồng người chơi từng bước

  1. Nạp mặc địnhHệ thống Code
    RemoteConfigDefaultSetterCakeOrder.SetupDefaultValues điền 3 từ điển; Firebase nhận qua SetDefaultsAsync.
    Giá trị nằm trong scene InitManagers (SerializeField), không phải file riêng.
  2. Fetch + kích hoạtHệ thống Code
    FetchAsync với cache 3 600 s (0 nếu vừa nâng version), sau đó ActivateAsync.
  3. Hết 4 giây vẫn vào gameHệ thống Code
    Nếu mạng chậm, StartTimeout báo "Proceeding with default values"; game dùng cache / mặc định.
  4. Chọn bộ levelHệ thống Live 16/11
    Boot chọn default; 13 key map_config_<map>_lv_all_override_default thay metadata + level của từng map.
  5. Manager đọc keyHệ thống Code
    Mỗi manager parse JSON của riêng mình; lỗi parse thì giữ config cũ.

Vận dụng cho game khác

  • Đóng toàn bộ bảng cân bằng vào mặc định APK, server chỉ ghi đè phần cần chỉnh: đổi được số mà không cần build, mất mạng vẫn chơi bình thường.
  • Dùng key ghi đè theo "author" để designer / QA thử bộ level riêng mà không đụng dữ liệu người chơi thật.
  • Cho phép ship dữ liệu map mới qua server trước khi bản client hiển thị map (như tacos, croissant ở đây).

Bảng tổng hợp mọi tính năng đã làm chi tiết: FoodiePop_ThietKeChiTiet.xlsx.

Mở khóa & điểm vào

Luôn chạy từ lúc boot: RemoteConfigManager.Awake nạp mặc định, fetch xong thì báo onRemoteValueAvailable. Quá thời gian chờ 4 giây (_fetchTimeout trong InitManagers.unity) game vẫn vào với giá trị mặc định / cache.

Điểm vào:

  • Boot: BootGameCookOrder.IEBootSequence → chọn author level, khởi tạo Firebase
  • Mọi manager đọc key qua RemoteConfigManager.GetString / GetLong / GetDouble
  • Bộ chọn author (OnGUI) chỉ hiện khi bản test bật _isShowDatasetSelection; bản release đặt 0
  • Popup Settings (bản test) có dropdown author để đổi bộ level lúc đang chạy

Cách hoạt động

  1. Scene InitManagers có RemoteConfigManager kèm danh sách IRemoteConfigDefaultValueSetter (có RemoteConfigDefaultSetterCakeOrder).
  2. Firebase khởi tạo xong → OnDoneInitFirebase gọi SetDefaultsAsync với 3 từ điển mặc định (long / double / string) do các setter điền, rồi FetchAsync.
  3. FetchAsync dùng khoảng cache firebaseRemoteConfigFetchInterval (release 3 600 s; lần chạy đầu sau khi đổi version app = 0 để lấy ngay).
  4. Fetch xong → ActivateAsync → FetchComplete → TriggerRemoteValueAvailable (IsRemoteValueAvailable = true, trạng thái Fetched).
  5. Song song, StartTimeout đếm 4 giây; hết giờ mà chưa có dữ liệu thì vẫn gọi TriggerRemoteValueAvailable và dùng giá trị mặc định / cache.
  6. Boot chọn author level default (SelectOverrideAuthor) → ApplySelectedAuthorOverrides đọc key map_config_<map>_lv_all_override_default; có giá trị thì ghi đè tạm (runtime string override) cho metadata và từng level của map.
  7. Từng manager đọc key của mình, parse JSON / chuỗi; parse lỗi thì giữ config cũ (log "use existing config").
  8. Manager nào cần giá trị mới nhất đăng ký onRemoteValueAvailable (Segment, UserBucketTracking, LastestVersionCheck, GameProgressScenario...).
