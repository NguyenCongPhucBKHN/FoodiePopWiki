Wiki thiết kế Foodie Pop! 1.15 (com.abi.foodpop, ABI Games), đọc ngược từ client: mọi ý trong tài liệu đều gắn nhãn cho biết dựa vào đâu. Tài liệu mô tả game đang chạy, không phải bản thiết kế gốc của studio.

Cổng chất lượng

  • fp_check: kiểm tra cấu trúc dữ liệu wiki (trường bắt buộc, nhãn bằng chứng, ảnh, link, anchor).
  • check_evidence: mọi trích dẫn Lớp.Method trong 57 trang tính năng phải có thật trong 1.15; toàn bộ 1 708 trích dẫn khớp, 0 lỗi; có 3 control đỏ.
  • Bộ kiểm dữ liệu (Tools/data/run_all.py, chạy lại --idempotent cho kết quả giống hệt): 1 357 file, 49 negative control đều đỏ đúng chỗ.
  • Pseudo-C: control --shift 1 cho 14,43 % (đỏ đúng), kiểm literal control +1/+7/+8 cho 0 %.
  • Mỗi lần dựng lại site cho file giống hệt từng byte.

Giới hạn

  • Giá trị chỉ nằm ở server (kết quả bảng xếp hạng, nội dung Inbox, luật tạo đội…) không đọc được: wiki chỉ mô tả phía client và giá trị mặc định.
  • Không gửi request mạng tới server của ABI: Remote Config lấy qua cache của chính client; tính năng xã hội chỉ đọc code và save.
  • Sự kiện chưa gặp khi playtest: ở Day 13–20 không thấy StageRace, Tower, Pass, Streak, League, TeamTreasure, Inbox, EventSale trên Home; các trang này dựa vào Code / APK / save.
  • Root tạm 19:40–19:42 ngày 16/11: chỉ để chép cache Remote Config và PlayerPrefs; đã tắt root và kiểm lại sau đó (su không còn). Bản chép là dữ liệu riêng tư, không đưa lên web.
  • Quảng cáo trong playtest: agent chơi không bấm nút xem quảng cáo nào. Ở màn thắng Day 15 nó bấm nút nhận "100" gem (thưởng thắng Super Hard) và quảng cáo hiện ra sau đó — lúc đầu ghi nhầm là rewarded, đối chiếu save cho thấy đó là inter đầu tiên (mốc level 15 của profile BLD). Hai quảng cáo playable không có nút đóng được xử lý bằng HOME + mở lại game.
  • Mọi số liệu của người chơi (tài khoản test, serverId) chỉ là dữ liệu máy thử; không có token, advertising id hay định danh cài đặt Firebase trong tài liệu.

Liên hệ với nghiên cứu clone 1.11

Trước đó đã có một dự án clone game ở bản 1.11 (F:\0_Phuc\Clone\Pop). Wiki này chỉ dùng nó làm gợi ý (công cụ, hướng đọc): mọi kết luận được đối chiếu lại với 1.15 trước khi đưa vào. Khác biệt kiểu giữa hai bản nằm ở Diff kiểu 1.11 → 1.15.

Cách dựng lại

Chạy từ thư mục dự án (FoodiePop), PYTHONIOENCODING=utf-8:

python Tools/data/run_all.py                      # chuyển và kiểm dữ liệu Data/
python Tools/decode/check_evidence.py             # kiểm trích dẫn code
python GameDesign/tools/fp_appendix.py            # sinh lại các trang phụ lục này
python GameDesign/tools/fp_check.py               # kiểm wiki
python GameDesign/tools/fp_site.py                # dựng site
python GameDesign/tools/fp_xlsx.py                # xuất 2 file Excel
python GameDesign/tools/fp_check.py --require-site

Các trang phụ lục

  • Remote Config: 1 174 key mặc định, giá trị live 16/11, trang tài liệu liên quan.
  • Level theo map và Danh sách map.
  • Sản phẩm IAP, Lệnh server.
  • Khoá localization, Enum quan trọng, Diff kiểu 1.11 → 1.15.
